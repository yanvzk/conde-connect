# CONDE CONNECT — versão inicial

Abra `index.html` no Chrome para testar localmente.

Esta versão é um protótipo front-end responsivo:
- Estudos
- Escola
- Área do professor
- Área do aluno
- Conexões
- Rotina
- Manifest para experiência instalável/PWA

Para ter login real, banco de dados, mensagens e contas de professor/aluno, será necessário publicar o front-end em um serviço de hospedagem e conectar um backend/autenticação.
